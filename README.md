\# Aerial Object Detection using YOLO and VisDrone



\## Project Overview



This project aims to develop an aerial object detection system using deep learning and drone-captured images from the VisDrone dataset.



The initial experiment focuses on detecting people and vehicles in aerial imagery using a YOLO-based object detection model.



\## Objectives



\- Explore object detection in aerial images.

\- Understand and prepare the VisDrone dataset.

\- Convert annotations into YOLO format.

\- Train a YOLO-based detection model.

\- Evaluate detection performance.



\## Dataset



\*\*VisDrone2019-DET\*\*



Dataset source: https://github.com/VisDrone/VisDrone-Dataset
